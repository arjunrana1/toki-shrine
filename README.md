# TimeShrine

An Android app that puts deliberate friction in front of the apps and websites you doomscroll.

It never blocks you outright. You pick what to put behind a wall, you pick what it should cost to get past it, and then you actually pay that cost — either typing out a passage of random words, or waiting out a countdown while holding the phone. If you still want in afterwards, that's a fine answer.

Deliberately friction-only. A hard blocker is a different product.

## Status

Pre-build. Phase 1 scope is settled; nothing open in the PRD. Next steps are design mockups and a technical spike to validate that Android's accessibility service reliably catches app launches on real hardware.

Android first. iOS is a separate architecture built on Apple's Screen Time APIs and is not committed to.
